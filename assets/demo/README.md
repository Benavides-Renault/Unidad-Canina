# Fotos ilustrativas del demo

Estas fotografías de Pexels ilustran registros ficticios. No muestran perros reales de ORYX ni acreditan propiedad, raza, pedigrí, entrenamiento o disponibilidad. Se reutilizan en varios registros del demo.

Las seis páginas originales, autores, licencia y SHA-256 están en `sources.json`, generado por `scripts/demo-photos.mjs --demo-only`. La licencia permite su uso en este contexto: https://www.pexels.com/license/.

El script exige `DEMO_MODE=true` y una base local `oryx_demo_*`; no cambia fotos existentes. Los archivos se cargan mediante la API privada con la misma autorización que cualquier foto de expediente. No se incluyen automáticamente en instalaciones normales.
